The Cryptographic Mathematics of Password Entropy

In cybersecurity and information theory, password strength is not determined by how "complex" or clever a human believes a string is, but by its mathematical entropy. Formulated by Claude Shannon, information entropy measures the quantitative uncertainty or unpredictability contained within an information sequence.

Computers attempting brute-force dictionary attacks do not guess based on human intuition; they systematically iterate through every mathematical permutation in the character pool. A password generated using standard CSPRNG (Cryptographically Secure Pseudo-Random Number Generator) algorithms forces attackers to exhaust astronomical search spaces.

The Password Entropy Equation

Entropy (E) = L × log2( N )

Where:
• L = Total password length in characters
• N = Total number of possible characters in the selected pool
• E = Entropy expressed in bits
Entropy Range Security Classification Brute-Force Feasibility (100 Billion Guesses/sec)
< 40 Bits Extremely Weak Cracked in seconds to minutes.
40 – 59 Bits Moderate Cracked in several days or weeks.
60 – 79 Bits Strong Resistant for centuries against standard clusters.
≥ 80 Bits Military / Quantum Grade Uncrackable within the lifespan of the universe.

Why Length Beats Complexity

Because the length variable \(L\) multiplies the logarithmic character pool size, adding 4 additional characters to a password increases resistance exponentially far more than substituting an '@' for an 'a'. A 16-character alphanumeric password is orders of magnitude stronger than an 8-character password filled with complex symbols.
