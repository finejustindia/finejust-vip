1. What is JSON (JavaScript Object Notation)?

JavaScript Object Notation (JSON) is the global standard, language-independent data interchange format defined by ECMA-404 and RFC 8259. Because it is lightweight, human-readable, and natively supported across all modern programming languages, JSON powers virtually all RESTful APIs, GraphQL payloads, and NoSQL databases worldwide.

2. Strict JSON Syntax Specifications

Unlike relaxed JavaScript object literals, RFC-compliant JSON enforces strict syntax requirements:

  • Double Quotes Only: Keys and string values MUST be wrapped in double quotes ("key": "value"). Single quotes ('key') are invalid.
  • No Trailing Commas: Commas must not follow the final element in an array or object.
  • Supported Types: String, Number, Boolean (true/false), null, Array ([]), and Object ({}). Functions and undefined are forbidden.

3. 5 Most Common JSON Parsing Errors

  1. Trailing Commas: Placing a comma after the last property before a closing brace }.
  2. Single Quotes: Using 'name': 'value' instead of "name": "value".
  3. Unquoted Object Keys: Omitting quotes on property keys ({ age: 25 }).
  4. Unescaped Special Characters: Failing to escape internal double quotes or backslashes (\", \\).
  5. Comments: JSON does not support inline comments (// comment or /* comment */).
